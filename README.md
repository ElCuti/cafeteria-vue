# ☕ Cafeteria Vue — Front-End Application
Proyecto autónomo de desarrollo Front-End que marca mi primera experiencia práctica con **Vue.js**. 

Como proceso natural de un desarrollador web, he decidido aprender por mi cuenta antes de dar en clase el framework Vue.js, mi intención con este proyecto es probar todo lo que me puede dar una herramientas así para el desarrollo front-end.

---

## 🔥 Funcionalidades Destacadas

* 🛒 **Carrito de Compras Persistente:** Gestión dinámica de productos seleccionados guardados mediante `localStorage` para conservar el estado tras recargar la página.
* 🚦 **Gestión de Vistas:** Navegación fluida entre diferentes secciones de la cafetería.
* ⚡ **Reactividad e Interacción:** Actualización del estado visual en tiempo real en respuesta a las acciones del usuario.
* 🌐 **Procesamiento Asíncrono:** Manejo de peticiones y flujos asíncronos con JavaScript nativo (`async/await`).

---

## 🛠️ Conceptos y Tecnologías Aplicados

Durante el desarrollo de este proyecto he podido poner a prueba los siguientes fundamentos de Vue.js:

### **Vue.js Core**
* **Reactividad:** Uso de `ref` para el manejo de estados mutables.
* **Propiedades Computadas:** Optimización del renderizado mediante `computed` (cálculo dinámico de totales del carrito).
* **Arquitectura de Componentes:** Creación y estructuración de componentes modulares y reutilizables.
* **Comunicación de Componentes:** Flujo de datos mediante `props` e intercambio de eventos con `emits`.
* **Vistas y Enrutamiento:** Control de navegación y renderizado condicional de vistas.

### **JavaScript Nativo (ES6+) & Web APIs**
* Manipulación del **`localStorage`** para la persistencia del carrito.
* Funciones asíncronas (`async` / `await` / Promises).
